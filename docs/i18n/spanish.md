## Características

- Vista previa en tiempo real (WYSIWYG) y una interfaz limpia y simple para una experiencia de escritura sin distracciones.
- Soporte para [CommonMark Spec](https://spec.commonmark.org/0.29/), [GitHub Flavored Markdown Spec](https://github.github.com/gfm/) y soporte selectivo para [Pandoc markdown](https://pandoc.org/MANUAL.html#pandocs-markdown).
- Extensiones Markdown como expresiones matemáticas (KaTeX), front matter y emojis.
- Soporte para párrafos y atajos de estilo en línea para mejorar tu eficiencia al escribir.
- Exportación de archivos **HTML** y **PDF**.
- Varios temas: **Cadmium Light**, **Material Dark**, etc.
- Varios modos de edición: **Source Code mode**, **Typewriter mode**, **Focus mode**.
- Pega imágenes directamente desde el portapapeles.
