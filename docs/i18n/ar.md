## الميزات

- معاينة فورية (WYSIWYG) وواجهة نظيفة وبسيطة لتجربة كتابة خالية من التشتيت.
- دعم [CommonMark Spec](https://spec.commonmark.org/0.29/)، و[GitHub Flavored Markdown Spec](https://github.github.com/gfm/)، ودعم انتقائي لـ [Pandoc markdown](https://pandoc.org/MANUAL.html#pandocs-markdown).
- إضافات Markdown مثل المعادلات الرياضية (KaTeX) وfront matter والرموز التعبيرية.
- دعم اختصارات الفقرات والأنماط المضمنة لتحسين كفاءة الكتابة.
- تصدير ملفات **HTML** و**PDF**.
- سمات متعددة مثل **Cadmium Light** و**Material Dark** وغيرها.
- أوضاع تحرير متعددة: **Source Code mode** و**Typewriter mode** و**Focus mode**.
- لصق الصور مباشرة من الحافظة.
