## 機能

- リアルタイムプレビュー（WYSIWYG）と、気を散らさないシンプルなインターフェース。
- [CommonMark Spec](https://spec.commonmark.org/0.29/)、[GitHub Flavored Markdown Spec](https://github.github.com/gfm/)、および [Pandoc markdown](https://pandoc.org/MANUAL.html#pandocs-markdown) の一部をサポート。
- 数式（KaTeX）、front matter、絵文字などの Markdown 拡張をサポート。
- 段落やインラインスタイルのショートカットに対応し、執筆効率を高めます。
- **HTML** と **PDF** を出力できます。
- **Cadmium Light**、**Material Dark** など、さまざまなテーマを搭載。
- **Source Code mode**、**Typewriter mode**、**Focus mode** など、複数の編集モードを搭載。
- 画像をクリップボードから直接貼り付けできます。

## 開発

Macaron を自分でビルドしたい場合は、[ビルド手順](../../docs/dev/BUILD.md) を参照してください。

- [ユーザードキュメント](../../docs/README.md)
- [開発者向けドキュメント](../../docs/dev/README.md)

Macaron に関する質問がある場合は、issue を作成してください。その際は issue 作成時のデフォルトフォーマットを使用してください。もちろん、直接 PR を送っていただけるのも大歓迎です。

## コントリビューション

Macaron は現在も開発中です。PR を作成する前に、[Contributing Guide](../../CONTRIBUTING.md) を確認してください。Macaron に機能を追加したい場合は、公開中の issues を参照してください。
