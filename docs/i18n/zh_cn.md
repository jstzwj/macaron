## 特性

- 实时预览（WYSIWYG）和简洁清爽的界面，带来无干扰的写作体验。
- 支持 [CommonMark 规范](https://spec.commonmark.org/0.29/)、[GitHub Flavored Markdown 规范](https://github.github.com/gfm/) 以及对 [Pandoc markdown](https://pandoc.org/MANUAL.html#pandocs-markdown) 的选择性支持。
- 支持数学公式（KaTeX）、front matter 和 emoji 等 Markdown 扩展。
- 支持段落和行内样式快捷方式，提升写作效率。
- 导出 **HTML** 和 **PDF** 文件。
- 提供多种主题：**Cadmium Light**、**Material Dark** 等。
- 提供多种编辑模式：**源码模式**、**打字机模式**、**专注模式**。
- 支持直接从剪贴板粘贴图片。

## 开发

如果你想自行构建 Macaron，请查看我们的[构建说明](../../docs/dev/BUILD.md)。

- [用户文档](../../docs/README.md)
- [开发者文档](../../docs/dev/README.md)

如果你对 Macaron 有任何疑问，欢迎提交 issue。提交时请尽量使用创建 issue 时提供的默认模板。当然，如果你直接提交 PR，我们也非常感谢。

## 贡献

Macaron 正在持续开发中。提交 PR 之前，请先阅读[贡献指南](../../CONTRIBUTING.md)。如果你想为 Macaron 添加新功能，请参考当前开放的 issues。
