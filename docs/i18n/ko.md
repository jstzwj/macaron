## 기능

- 실시간 미리보기(WYSIWYG)와 깔끔하고 단순한 인터페이스로 방해 없는 글쓰기 경험을 제공합니다.
- [CommonMark Spec](https://spec.commonmark.org/0.29/), [GitHub Flavored Markdown Spec](https://github.github.com/gfm/), 그리고 [Pandoc markdown](https://pandoc.org/MANUAL.html#pandocs-markdown)을 선택적으로 지원합니다.
- 수식(KaTeX), front matter, 이모지 등 Markdown 확장을 지원합니다.
- 문단 및 인라인 스타일 단축키를 지원하여 작성 효율을 높입니다.
- **HTML** 및 **PDF** 파일로 출력할 수 있습니다.
- **Cadmium Light**, **Material Dark** 등 다양한 테마를 제공합니다.
- **Source Code mode**, **Typewriter mode**, **Focus mode** 등 다양한 편집 모드를 제공합니다.
- 클립보드에서 이미지를 바로 붙여넣을 수 있습니다.

## 개발

직접 Macaron을 빌드하고 싶다면 [빌드 안내](../../docs/dev/BUILD.md)를 확인하세요.

- [사용자 문서](../../docs/README.md)
- [개발자 문서](../../docs/dev/README.md)

Macaron에 대해 궁금한 점이 있다면 언제든지 issue를 작성해 주세요. 작성할 때는 issue 생성 시 제공되는 기본 형식을 사용해 주세요. 물론 PR을 바로 보내주셔도 매우 감사하겠습니다.

## 기여

Macaron은 현재 개발 중입니다. pull request를 만들기 전에 [기여 가이드](../../CONTRIBUTING.md)를 읽어 주세요. Macaron에 기능을 추가하고 싶다면 열려 있는 issues를 참고하세요.
