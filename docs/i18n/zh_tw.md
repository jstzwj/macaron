## 功能

- 即時預覽（WYSIWYG）與簡潔清爽的介面，帶來無干擾的寫作體驗。
- 支援 [CommonMark 規範](https://spec.commonmark.org/0.29/)、[GitHub Flavored Markdown 規範](https://github.github.com/gfm/) 以及對 [Pandoc markdown](https://pandoc.org/MANUAL.html#pandocs-markdown) 的選擇性支援。
- 支援數學公式（KaTeX）、front matter 與 emoji 等 Markdown 擴充功能。
- 支援段落與行內樣式快捷鍵，提升寫作效率。
- 匯出 **HTML** 與 **PDF** 檔案。
- 提供多種主題：**Cadmium Light**、**Material Dark** 等。
- 提供多種編輯模式：**原始碼模式**、**打字機模式**、**專注模式**。
- 支援直接從剪貼簿貼上圖片。

## 開發

如果你想自行建置 Macaron，請查看我們的[建置說明](../../docs/dev/BUILD.md)。

- [使用者文件](../../docs/README.md)
- [開發者文件](../../docs/dev/README.md)

如果你對 Macaron 有任何問題，歡迎提交 issue。提交時請盡量使用建立 issue 時提供的預設格式。當然，如果你直接提交 PR，我們也會非常感謝。

## 貢獻

Macaron 仍在持續開發中。提交 PR 之前，請先閱讀[貢獻指南](../../CONTRIBUTING.md)。如果你想為 Macaron 增加新功能，請參考目前開放的 issues。
