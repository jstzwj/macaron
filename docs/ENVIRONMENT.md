# Environment

| Name                         | Description                                                 |
| ---------------------------- | ----------------------------------------------------------- |
| `MACARON_DEBUG`             | Enable debug mode.                                          |
| `MACARON_DEBUG_KEYBOARD`    | Print more keyboard information when debug mode is enabled. |
| `MACARON_ERROR_INTERACTION` | Never show the error dialog to report bugs.                 |
| `MACARON_PANDOC`            | Overwrite the pandoc path.                                  |

## Development

| Name                                 | Description                                                  |
| ------------------------------------ | ------------------------------------------------------------ |
| `MACARON_EXIT_ON_ERROR`             | Exit on the first error or exception that occurs.            |
| `MACARON_DEV_HIDE_BROWSER_ANALYZER` | Don't show the dependency analyzer.                          |
| `MACARON_IS_STABLE`                 | **Please don't use this!** Used to identify stable releases. |
